# Querencia Tastenkürzel: feste Kürzel der Querencia-Programme.
#
# Aufbau: [Programm] als Überschrift, darunter je Zeile
#   Kürzel = Beschreibung
# Kürzel werden mit „+“ verbunden, mehrere Kürzel für dasselbe mit „ / “.
# Zeilen mit „#“ sind Kommentare. Die Reihenfolge bleibt erhalten.
#
# Seit Kürzel 0.2.3 englisch (msgid): Überschriften und Beschreibungen
# übersetzt der Katalog po/querencia-kuerzel.pot, die Tastenfolgen mit dem
# Kontext „key“ (englische Tastennamen Ctrl, Shift, Enter, Delete, Insert,
# Home, End, Page Up, Page Down, Print, Backspace, Menu, Esc, Click). Nach
# jeder Änderung: python3 werkzeug/i18n.py pot && update, alle po/*.po
# ergänzen, pruefen.
#
# Quellen (G2-R, 18.10.2026), jeweils die im Programm fest eingebauten
# Kürzel des Live-Stands:
#   Arbeitsfläche   querencia-runtime crates/querencia-desktop (QE-02)
#   Dateien         querencia-runtime crates/querencia-dateien src/menue.rs (KUERZEL, KUERZEL_IM_BEREICH)
#                   mit src/suche/mod.rs (Strg+F, Welle C2) und src/ansichtskern.rs
#                   (Kontextmenü); Reiter, Kompaktansicht und Auswahl umkehren aus
#                   Welle C3 (Nachtrag runtime-abloesung, 24.10.2026)
#   Terminal        querencia-terminal-dev Tag terminal/0.3.0 src/tabs.rs
#                   (shortcut, shortcut_overview) und src/clipboard.rs
#                   (Nachtrag kuerzel-reiter, 21.10.2026; live seit
#                   20.10. 23:34)
#   Editor, Bilder  querencia-werkstatt-g2e-apps prototyp-*/src (live 19:36)
#   Bildschirmfoto  querencia-screenshot-dev src/editor.rs (0.2.4;
#                   Strg+Q aus Tag screenshot/0.2.8, QD-051)
#   Taschenrechner  querencia-rechner src/fenster.rs (0.1.0)
#   Dateisuche      querencia-dateisuche src/fenster.rs (0.1.0)
# Ändert ein Programm seine Kürzel, muss diese Datei mitgezogen werden.

[Desktop]
F2 = Rename the selected icon
Ctrl+A = Select all icons
Esc = Clear the selection
Ctrl+Click = Add an icon to the selection or remove it
Shift+Click = Select the icons up to here

[Files]
Ctrl+T = New Tab
Ctrl+N = New Window
Shift+Ctrl+N = Create Folder
Ctrl+O = Open
Shift+Ctrl+O = Open in New Tab
Middle mouse button = Open the folder in a new tab
Alt+Enter / Ctrl+I = Properties
Shift+Ctrl+W = Close All Windows
Ctrl+W = Close tab (the last one closes the window)
Ctrl+X = Cut
Ctrl+C = Copy
Ctrl+V = Paste
Ctrl+A = Select All
Shift+Ctrl+I = Invert Selection
F2 = Rename
Shift+F2 = Rename, selecting the whole name
Delete = Move to Trash
Shift+Delete = Delete (asks first)
Menu / Shift+F10 = Context menu
Esc = Stop loading
Ctrl+R / F5 = Reload
F9 = Sidebar on or off
Ctrl+H = Show Hidden Files
Ctrl++ / Ctrl+- / Ctrl+0 = Zoom In / Zoom Out / Normal Size
Ctrl+1 = Icon View
Ctrl+2 = List View
Ctrl+3 = Compact View
Alt+↑ = Parent Folder
Alt+← = Back
Alt+→ = Forward
Alt+Home = Home Folder
Ctrl+L = Enter a location
Ctrl+F = Search (Esc stops the search or closes the bar)
Ctrl+D = Add Bookmark
Ctrl+Page Up / Ctrl+Page Down = Previous / next tab
Shift+Ctrl+Page Up / Shift+Ctrl+Page Down = Move tab left / right
Alt+1 … Alt+0 = Switch to tab 1 … 10
F1 = Online Help

[Querencia Terminal]
Ctrl+Shift+T = New Tab
Ctrl+Shift+W = Close tab
Ctrl+Shift+Q = Close window
Ctrl+Page Up / Ctrl+Page Down = Previous / next tab
Ctrl+Shift+Page Up / Ctrl+Shift+Page Down = Move tab left / right
Alt+1 … Alt+9 = Switch to tab 1 … 9
Middle-click on a tab = Close tab
Double-click on the empty tab bar = New Tab
Ctrl+Shift+C = Copy
Ctrl+Shift+V / Shift+Insert = Paste
Menu / Shift+F10 = Context menu

[Text Editor]
Ctrl+N = New Document
Ctrl+O = Open
Ctrl+S = Save
Ctrl+Shift+S = Save As
Ctrl+W = Close Document
Ctrl+Q = Quit
Ctrl+Z = Undo
Ctrl+Shift+Z = Redo
Ctrl+A = Select All
Ctrl+F = Search
Ctrl+G / Ctrl+Shift+G = Find Next / Find Previous
Ctrl+H = Replace
Ctrl+I = Go to Line
Ctrl+Alt+Page Up / Ctrl+Alt+Page Down = Previous / next document

[Image Viewer]
Ctrl+O = Open
Alt+Enter = Image Properties
Ctrl+W = Close
Ctrl+Q = Quit
Ctrl+R / Ctrl+Shift+R = Rotate right / left
+ / - = Zoom In / Zoom Out
Ctrl+0 / 1 = Original Size
F = Fit to Window
F11 = Fullscreen
F5 = Slideshow
← / → = Previous / next image
Home / End = First / last image

[Screenshot]
Print = Take a screenshot (screen, window or area)
Alt+Print = Screenshot of a window
Ctrl+N = New screenshot (in the editing window)
Ctrl+S = Save
Ctrl+C = Copy to Clipboard
Ctrl+W / Ctrl+Q = Close
Ctrl+Z = Undo
Ctrl+Shift+Z / Ctrl+Y = Redo
Esc = Cancel the capture or the tool

[Calculator]
0 … 9 / , = Digits and decimal separator
+ - * / % = Operators and percent
Enter / = = Result
Backspace = Delete the last digit
Delete = Clear entry (C)
Esc = Clear all (AC)
S / Q / R / V = Square root / square / reciprocal / sign
Ctrl+C / Ctrl+V = Copy / Paste
Ctrl+Q = Quit

[Search for Files]
Delete = Move the match to the trash
Ctrl+C = Copy path
Menu / Shift+F10 = Context menu
Esc = Cancel search

[Keyboard Shortcuts (this window)]
Esc / Ctrl+W = Close
